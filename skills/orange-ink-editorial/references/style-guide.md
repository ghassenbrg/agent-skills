# Visual style guide

## Brand feeling
Curious, intelligent, warm, exploratory, technically literate, and easy to understand. Never preachy or overly corporate.

## Color roles
- Black/charcoal: structure, character, most lettering
- Orange: energy, emphasis, arrows, underlines, idea marks
- Cream/off-white: calm base
- Golden yellow: warmth/glow only

## Texture
Use dry-brush, marker, paper, ink, or light gouache texture. Avoid perfectly sterile vectors.

## Topic translation
- Tech: code, cloud, database, terminal, nodes, systems
- Science: flask, orbit, atom, telescope, lightbulb
- History: map, column, scroll, artifact
- Travel: map, compass, globe, camera
- Learning: books, notebook, pencil, question marks

Always choose the smallest useful subset.
