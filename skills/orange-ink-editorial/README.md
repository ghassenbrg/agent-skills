# Orange Ink Editorial Style Skill

This bundle contains a reusable Agent Skill for generating images in the orange ink editorial visual language.

Main entry point: `SKILL.md`

Supporting material:
- `references/style-guide.md`
- `references/prompt-patterns.md`
- `references/platform-presets.md`
- `assets/` reference images

Typical request after installing:

> Use the orange-ink-editorial skill to create a LinkedIn cover about platform engineering.

or

> Use the orange-ink-editorial skill to make an Instagram post where the reference mascot explains APIs.
